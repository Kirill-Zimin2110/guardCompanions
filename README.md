# Guard Companion — мод для Minecraft 1.21.1 (NeoForge)

Компаньон-охранник: humanoid-моб, который следует за владельцем, сражается, строит дом
по русской чатовой команде и ловит рыбу в сундук.

## Возможности

- **Спавн-яйцо** (`guardcompanion:companion_spawn_egg`): креатив-инвентарь (вкладка Spawn Eggs)
  или крафт — железные слитки по кругу + алмаз в центре.
  При использовании яйцо привязывает компаньона к ближайшему игроку.
  Без владельца можно «приручить» костью.
- **Следование**: держится в 3–5 блоках, телепорт к владельцу дальше 30 блоков.
- **30 сердец (60 HP), базовый урон 3**, броня и скорость балансируемы; броню и инструменты
  можно надевать ПКМ (в т.ч. в главную руку — урон растёт от оружия, как в ванилле).
- **Режимы атаки** — ПКМ по компаньону с пустой рукой (циклично) или команда:
  1. `враждебные` — атакует только монстров (zombie, skeleton, creeper...);
  2. `мирные` — атакует животных (коровы, свиньи, овцы...);
  3. `всё` — уничтожает всё, кроме владельца и других компаньонов;
  4. `стоять` — стоит на месте и не атакует.
- **Смерть**: с шансом 50% дропает яйцо призыва.
- **Строитель (итерация 2)**: `/компаньон построй двухэтажный дом 9x9` — сам срубает деревья,
  добывает камень, крафтит доски/дверь/лестницу и строит дом (5x5–13x13, 1–2 этажа).
- **Рыбак (итерация 2)**: `/компаньон рыбачь` — ловит рыбу у воды и складывает в ближайший сундук.
- **Отмена**: `/компаньон стоп` (вернётся к режиму «враждебные»).
- **Статус**: `/компаньон` без аргументов.

## Сборка

```bash
./gradlew build   # или gradle build
```

Готовый мод: `build/libs/guardcompanion-1.0.0.jar` — положить в папку `mods/`
(Minecraft 1.21.1 + NeoForge 21.1.x).

## Структура кода

| Класс | Назначение |
|---|---|
| `entity/CompanionEntity` | сущность: владелец, режимы, инвентарь-рюкзак, экипировка, дроп яйца |
| `entity/CompanionMode` | режимы атаки и задач |
| `ai/CompanionGoals` | AI-цели: следование, стоянка, таргетинг по режиму, строитель, рыбак |
| `ai/CompanionBuildPlan` | генерация/сериализация чертежа дома |
| `item/CompanionSpawnEgg` | яйцо призыва |
| `command/CompanionCommands` | русская команда `/компаньон ...` |
| `registry/*` | регистрация сущности, предмета, звуков |
| `client/ClientSetup` | рендер humanoid + слои брони |

Звуки объявлены как свои `SoundEvent` и замаплены в `sounds.json` на ванильные файлы.
